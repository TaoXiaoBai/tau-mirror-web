# Tau Mirror Web

[English](./README.md) · **简体中文**

[Pi](https://github.com/earendil-works/pi) 编程助手的浏览器界面。

终端里照常运行 Pi，再从电脑或手机浏览器继续同一段对话。

</div>

## 一句话说明

Tau Mirror Web 是一个轻量的 HTTP + WebSocket 扩展，用来把正在运行的 Pi 会话镜像到浏览器。它不会替代 Pi，也不会额外启动一个独立 Agent：终端与网页共享同一个会话、模型、工具和事件状态。

## 为什么使用它

- 保留原来的终端工作方式，不需要迁移到另一套 Agent。
- 在浏览器里更舒服地阅读长回答、发送消息和查看历史。
- 输入 `/qr`，就能从手机打开当前 Pi。
- 直接查看工具调用、思考过程、上下文占用和错误信息。
- 不手改模型配置，也能管理 OpenAI 兼容供应商。
- 完整历史始终可用，长会话按需加载，不会为了提速偷偷截断。

## 快速开始

### 从 GitHub 安装

```bash
pi install git:github.com/TaoXiaoBai/tau-mirror-web
```

然后像平时一样启动 Pi，打开 Tau 显示的地址。默认地址是：

```text
http://localhost:3001
```

### 使用本地代码

```bash
git clone https://github.com/TaoXiaoBai/tau-mirror-web.git
cd tau-mirror-web
```

Windows PowerShell 中，可以在启动 Pi 前把前端目录指向本地代码：

```powershell
$env:TAU_STATIC_DIR = (Resolve-Path .\public)
pi
```

也可以把扩展路径写进 `~/.pi/agent/settings.json`。

### 从手机打开

在 Pi 中输入 `/qr`，扫描显示的二维码。手机必须能访问运行 Pi 的电脑。如果 Tau 不只对本机开放，请先阅读下面的安全说明。

## 主要功能

### 对话界面

- 实时流式回答
- Markdown 和数学公式
- 一键复制、粘贴图片、拖拽图片
- 思考过程和工具卡片
- 模型或 API 错误直接显示在对话中
- Pi 工作时可以先排队下一条消息
- 对话框和面板会动态为最新输出让出空间，不再遮住最后一段
- 自适应手机、平板横竖屏、笔记本和超宽屏桌面
- 稳定的历史滚动和“跳转最新消息”按钮
- 旧历史和高开销内容按需加载

### 模型与供应商

模型选择器同时也是供应商管理入口：

1. 打开模型菜单。
2. 点击底部的 **添加供应商**，或点击现有供应商旁边的 **编辑**。
3. 填写 Base URL 和 API Key。
4. 测试并保存。
5. Tau 会读取该供应商的模型，并注册给 Pi 使用。

支持 OpenAI 兼容接口。模型 ID 开头的 `/` 会原样保留，例如 `/CN/gpt-4o` 保存后仍然是 `/CN/gpt-4o`。

### 规划模式

网页会同步 Pi 后端的真实规划状态，支持规划、执行、停止、继续留在规划状态，以及补充要求后重新规划。工具权限跟随后端状态变化，不依赖网页端的乐观切换。

### 省 Token

顶部工具栏和 **设置 → 对话** 中都有 **省 Token** 入口。

它采用比较保守的方式：开启时关闭思考，并记住原来的思考强度；关闭后再恢复。它不会截断历史、改写提示词、关闭工具，也不会强行写入某个供应商专属的输出长度参数。

### 会话

- 浏览和搜索历史会话。
- 恢复旧会话并继续对话。
- 持久化重命名历史会话。
- 只允许删除已经停止、且位于 Pi 会话目录中的 `.jsonl` 历史文件。
- 通过分页保留完整历史，不用截断换取速度。

### 外观与语言

六套配色主题仍可单独选择。在 **设置 → 外观 → 明暗模式** 中，可以固定当前主题、跟随操作系统、固定亮色 / 暗色，或按本地时间自动切换。时间模式会在 19:00 至次日 07:00 使用暗色，白天恢复偏好的亮色主题。

第一次打开时，网页会跟随浏览器或系统语言。中文环境使用简体中文，其他环境使用英文。之后可以在 **设置 → 语言** 中随时修改。

## 配置

Tau 可以通过环境变量配置，也可以在 `~/.pi/agent/settings.json` 中加入可选的 `tau` 配置块。

| 环境变量 | 默认值 | 说明 |
|---|---:|---|
| `TAU_MIRROR_PORT` | `3001` | HTTP 和 WebSocket 端口 |
| `TAU_HOST` | `127.0.0.1` | 监听地址；需要带认证的局域网访问时再显式设为 `0.0.0.0` |
| `TAU_STATIC_DIR` | 内置 `public/` | 使用其他目录中的网页文件 |
| `TAU_DISABLED` | `0` | 设为 `1` 时不自动启动 |
| `TAU_USER` / `TAU_PASS` | 空 | 开启 HTTP Basic 登录验证 |

配置示例：

```json
{
  "tau": {
    "port": 3001,
    "user": "pi",
    "pass": "change-me"
  }
}
```

常用 Pi 命令：

```text
/tau        查看或打开 Tau
/tau-start  启动镜像服务
/tau-stop   停止镜像服务
/qr         为其他设备显示二维码
```

网页中配置的供应商保存在：

```text
~/.pi/agent/models.json
```

升级扩展后，请彻底退出并重新启动 Pi，让新的后端和 RPC 行为生效。`/reload` 不能加载新的后端逻辑。

## 安全与网络访问

Tau 运行在 Pi 进程中，能够接触你的对话和工具。默认只绑定到本机回环地址：

```powershell
$env:TAU_HOST = "127.0.0.1"
```

如果绑定到 `0.0.0.0`，或者需要从手机和其他电脑访问：

- 设置 `TAU_USER` 和 `TAU_PASS`，或在 Pi 配置中填写等效账号密码。未配置并启用认证时，Tau 会拒绝请求的非回环地址，并安全回退到 `127.0.0.1`。
- 只在可信的局域网或私人网络中使用。
- 不要在没有额外安全代理和身份验证的情况下，把端口直接暴露到公网。
- 把网页地址和二维码视为进入 Pi 会话的凭证。

会话文件操作被限制在 Pi 会话目录中的 `.jsonl` 文件。正在运行的会话不能删除。文件浏览、图片预览和系统打开操作只能访问当前工作区；HTTP 与 WebSocket 请求会校验来源并限制大小。

可选的 `extensions/imessage-bridge.ts` 必须通过 `BB_PASSWORD` 和 `BB_PHONE` 环境变量配置，不再包含默认凭据或私人收件人。

## 工作原理

```text
Pi 终端  <──>  Pi 进程 + Tau 扩展（HTTP / WebSocket）  <──>  浏览器
```

扩展订阅 Pi 的事件，再把状态和流式更新发送给所有已连接的浏览器标签页。网页操作通过扩展调用 Pi 的正常接口，因此终端和网页只是同一会话的两个入口。

## 常见问题

### 页面空白，或者仍然是旧界面

- 按 `Ctrl+F5` 强制刷新。
- 关闭网页标签页后重新打开。
- 如果改动涉及后端，请彻底退出并重新启动 Pi。

### 浏览器连不上

- 确认 Pi 正在运行。
- 输入 `/tau` 查看正确地址。
- 检查 Windows 防火墙是否拦截了端口。
- 手机访问时，确认手机与电脑之间网络可达。

### 看不到某个供应商或模型

打开模型选择器，点击 **刷新模型**。检查供应商的 Base URL、API Key，以及 `/v1/models` 接口是否兼容。已经写在 `models.json` 中的供应商，也可以继续从模型选择器编辑。

### 长会话打开比较慢

Tau 会优先显示最新消息，再按需读取更早的历史。这样可以更快进入可用状态，同时保留完整对话。特别大的图片或工具结果，在真正展开时仍可能需要更多时间。
